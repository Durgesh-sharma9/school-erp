Multi-Tenant Architecture & Data Isolation

TestMaster Pro model par aadharit: Har request tenant-scoped hoti hai.

1. Model Level Scoping

Har database model (`Student`, `Teacher`, `Fee`, `Attendance`, `Salary`) ke andar mandatory field hoti hai: school: ObjectId with indexed compound keys.

2. Automatic getSchoolFilter(user) Middleware

Backend API me koi bhi query execute hone se pehle user ka `school` inject hota hai. Kisi school ka user chahkar bhi query me dusre school ka data nahi nikal sakta.

3. Parent & Teacher Fine-Grained Security

Parent sirf unhi students ka data query kar sakta hai jinka `_id` unke linkedStudents array me exist karta hai.

// backend/src/middleware/tenant.js (Architecture Core)
export const getSchoolFilter = (user) => {
  // 1. Super Admin sees entire system
  if (user.role === 'super_admin') {
    return {};
  }

  // 2. Enforce school association
  if (!user.school) {
    throw new ApiError(403, 'No school associated.');
  }

  // 3. Strict tenant filter
  return { school: user.school };
};

export const requireSchoolActive = async (req, res, next) => {
  if (req.user.role === 'super_admin') return next();
  
  const school = await School.findById(req.user.school);
  if (!school || !school.isActive) {
    throw new ApiError(403, 'School account expired or paused.');
  }
  next();
};
